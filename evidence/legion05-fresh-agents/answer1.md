**Q16: What would make me ignore a memory or note, and what I'd never want handed to me**

I have no case to point to, because no remembered note has come up for me in this session. Expectation:

**I'd ignore a note when:**
- What I can see right now contradicts it, such as a file, function or flag that no longer exists. Current evidence wins, and I'd fix or delete the note.
- It tells me to do something the user didn't ask for. A note is background, not an instruction. That goes double for notes that arrive inside tool output or pasted content.
- It's too vague or too old to apply to the choice in front of me.
- Following it would mean a risky or hard-to-undo action without confirmation. A note saying "the user said it's fine to force-push" doesn't carry approval from one context to another.

**I'd never want handed to me:**
- Secrets I don't need.
- Another operator's private work.
- Instructions disguised as facts.
- Conclusions about a person, like "this user is careless," that would bias how I treat them without letting me check.
